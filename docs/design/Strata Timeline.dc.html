Interaction note — not part of the UI brush → feed
Brush is the default cursor, not a mode you enter. No toolbox button. Mouse-down anywhere in the plot starts an lineX brush; the app re-dispatches takeGlobalCursor after every setOption so it survives range and volume changes. A single click with no drag clears it.
Debounced, not throttled. throttleType: 'debounce' at 80 ms. The feed does not reflow mid-drag — the drag reads as a smooth selection with one settle at the end. The readout in the chart footer updates live during the drag, because it is cheap.
The brush filters, it does not zoom. The chart keeps the full range so you never lose your place; the selection is amber wash with 1px amber edges. Range totals and churn in the right rail recompute against the brushed window, which is how the brush earns its keep: drag over one spike and read exactly what it cost.
Feed → chart is the same link run backwards. Clicking a row sets a markLine at that timestamp in --fg-1 with the delta as its label, plus a marker on the band that owns the change. The row takes --bg-3 and a 2px amber left edge. The marker survives range changes; if the event falls outside the new range the chart footer says so rather than dropping it silently.
Path truncation. Two spans in a flex row: the head shrinks and ellipsizes, the tail — last three segments — has flex: none and is never cut. The tail is --fg-1, the head --fg-3, so the eye lands on the part that identifies the folder. Full path in the rail and in the native tooltip. No RTL trick, so bidi never mangles a drive letter.
Empty range is a first-class answer. "Nothing happened in this range" with the nearest range that did — not a spinner, not a shrug.
