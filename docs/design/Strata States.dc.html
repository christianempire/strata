The journal keeps recording while Strata sleeps, so a deferral costs resolution in the timeline, not data. The band it affects is drawn with a dashed top edge until the next successful tick fills it in.
Rule. Deferral is stated as a decision with a reason and a next attempt, never as an error and never as silence. The override is one click and always available. This is the only state with a coloured border on the whole panel.

05 Honest undercount running unelevated on C:

The gap is drawn, not hidden: a hatched band on every bar, a hatched top band on the timeline stack, and a row in the Explorer list that cannot be opened. Nowhere does the interface show a total that quietly excludes it.
Rule. An estimate is never rendered in the same ink as a measurement. Hatching means "we could not read this", and the arithmetic that reconciles Strata's total with the operating system's is on screen rather than in a tooltip — a 30 GB discrepancy with no explanation reads as a bug.

These bytes exist once on disk and are reached from more than one path. Strata counts them where it first saw them and shows every later path as a link, so the volume total stays honest. Deleting this path frees nothing.
counted at C:\Program Files\WindowsApps\component-store\10.0.26100
Rule. A link is a fact about the filesystem, not a failure, so it gets the calm blue of the series ramp rather than a warning colour — but it is stated plainly, with the path where the bytes are counted and the consequence for deleting. Linked bytes are shown at apparent size with unique size beside them, never silently zeroed.
07 Detached volume history still browsable
F: Archive-USB-4TB ◌ not connected
Last seenSun 3 Aug 19:22 · 16 days ago Last known2.31 TB of 3.64 TB used Snapshots kept4,182 · 11 months Retentionheld indefinitely while detached
Everything reads normally — treemap, timeline, compare — with one difference: the header is dated rather than live, and no scan is scheduled. Nothing about the history is greyed out; it is not stale, it is finished.
Rule. Absent hardware never removes data. A detached volume drops out of live status and stays in history at full fidelity, dashed rather than dimmed, with its own explicit last-seen date instead of a stale "now".
