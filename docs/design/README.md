# Design mockups

**Empty on purpose.** Phase 3's Angular UI is gated on mockups landing here.

The project brief is explicit: build to the mockups, do not invent a visual language, do not accept a
component library's defaults. If this directory is still empty when Phase 3b starts, stop and ask
rather than guessing.

Expected: the five screens described in `docs/ARCHITECTURE.md` — Overview, Timeline, Explorer,
Compare, Settings. Dark theme, dense, information-first. An instrument panel, not a marketing page.

The API half of Phase 3 is **not** gated on these and can be built and verified first.
