Palette and type scale
Every value below is fixed. Backgrounds and text are warm neutrals — a little yellow chroma keeps a panel this dark from reading blue-cold at night. All values were generated in OKLCH, so the twelve series hues sit on one lightness plane and none of them fights the others for attention.

One lightness, one chroma, twelve hues about 30° apart. No series dominates by brightness, all twelve take an 11px label in #0f0d0b at 4.5:1 or better, and stacked bands read as one family. Assign by stable directory hash, not by rank, so Users keeps its colour across every screen and across a re-scan that reorders it.
Series 13 and beyond fold into other in #4b4743 — the only desaturated band, so "everything else" never looks like a named directory. Closest pairs are s1/s2 and s7/s8; both are separated in the stack by adjacency ordering and in the treemap by an always-drawn label.

Nine steps, no more. Sans carries language; mono carries every number and every path, with font-variant-numeric: tabular-nums set globally so columns of bytes align on the decimal without per-cell work.
Numbers, units, time
Binary sizes, Windows labels.
1 GB = 1024³ bytes, written GB and not GiB, so Strata and File Explorer agree on screen. Stated once in Settings, never re-explained in the UI.
Never rounded into meaninglessness.
Three significant figures minimum: −16.78 GB, 550 GB, 92.5 GB. Exact byte count on hover, always. A unit on every figure; no bare numbers.
Counts are grouped, not abbreviated.
3,053,173 files — not 3.1M. File-count deltas carry a sign: −15 files.
UTC in, local out.
Snapshots and events arrive UTC and always display in the machine's local zone, 24-hour: Tue 11 Aug 14:07. The zone is stamped once in the top bar; any absolute timestamp carries its UTC offset on hover. Range edges snap to local midnight, not UTC midnight.
Theme scope
Dark is the only theme. A light theme is explicitly out of scope.

All values ship as CSS custom properties on :root, and ECharts reads them via getComputedStyle at chart init — so a light set could be added later as a second block without touching a component. Nothing in the layout assumes it, and no toggle is drawn.
Density
Table row 26px. Panel padding 14px, gutter 24px. Square corners; 2px maximum on chips. No shadows anywhere — elevation is one background step plus a 1px rule. Nothing in this interface has 40px of padding.
